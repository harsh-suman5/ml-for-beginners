## 📂 Repository Structure

Maine aapke files ko niche diye gaye table mein categorize kiya hai taaki navigation aasaan ho:

| Category | File/Folder | Description |
| :--- | :--- | :--- |
| 📁 **Core Modules** | `logistic regression/` | Logistic regression notebooks aur probability curves. |
| 📁 **Learning** | `pandas --tutorials/` | Pandas library ke detailed tutorials. |
| 📁 **Analysis** | `tableau analysis/` | Data visualization ke liye Tableau workbooks. |
| 📓 **Notebooks** | `new.ipynb` to `new6.ipynb` | Alag-alag ML experiments aur data cleaning notebooks. |
